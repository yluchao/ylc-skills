# 纳瓦尔思维（战略层）

源自 Naval Ravikant 的理念，用于审视学习目标的战略价值。

## 核心原则

### 1. 杠杆思维
- 三种杠杆：劳动力、资本、**代码与媒体**（无需许可的复制边际成本为零的杠杆）。
- 学习时的应用：优先学习"一次学会、反复复用"的知识（编程、写作、销售、判断力），而非"每次都要重做"的技能。
- 问：这个领域的知识能否被打包成作品/工具/内容，持续产生回报？

### 2. 特殊知识（Special Knowledge）
- 特殊知识 = 无法通过培训批量教会的知识，来自个人天赋、兴趣与经历的交叉点。
- 学习时的应用：找到「用户已有的独特经验 × 新领域」的交叉面，从交叉面切入。例如做过电商运营的人学数据分析，就从"店铺流量分析"切入，而不是从统计学公理切入。
- 问：用户学完之后，哪类组合能力的人群会变得稀缺？

### 3. 复利思维
- 所有回报——财富、关系、知识——都来自复利。
- 学习时的应用：优先选"知识本身会产生知识"的学习路径（地基概念 > 热门框架；原理 > 祖传配方）。
- 问：这个领域三年后的知识还值钱吗？学它会不会让下一个领域更好学？

### 4. 第一性原理
- 剥掉类比和惯性，回到事实的基本面推理。
- 学习时的应用：把领域拆到不可再拆的基本概念，从基本概念向上重建理解，而不是从流行术语向下猜。
- 问：如果这个领域今天刚被发明，它的说明书第一页会写什么？

### 5. 长期主义 + 胜负标准
- 用长期博弈的眼光选择战场：玩长期游戏，和长期的人玩。
- 学习时的应用：帮用户定义"学会了"的可验证标准（能做出什么、能教会谁、能通过什么检验），而不是模糊的"懂了"。

## 战略诊断输出格式

对用户目标依次回答：
1. 杠杆判断：高/中/低 + 理由
2. 专长交叉点：与用户已有储备的组合优势
3. 复利判断：领域半衰期
4. 内核 20%：第一性原理拆解出的最小核心
5. 修正建议：若目标有虚荣成分或边界过大，给出收窄后的目标

## 纳瓦尔式语言风格参考

- 直接给判断，不给骑墙结论。
- 用具体例子代替抽象说教。
- 敢于说"这个目标不值得投入这么多"，并给出替代方案。
