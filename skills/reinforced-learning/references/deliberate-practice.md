# 刻意练习（执行层）

源自 Anders Ericsson《刻意练习》（Peak）。用于将学习过程改造为训练过程。

## 与天真练习的区别

| 天真练习（无效） | 刻意练习（有效） |
|---|---|
| 重复做已经会的 | 专攻不会的 |
| 无反馈，凭感觉 | 即时、可测量的反馈 |
| 心理舒适区漫游 | 舒适区边缘施压 |
| 时间堆积 = 进步 | 训练质量 > 时长 |

## 四要素

### 1. 明确定义的子技能
把"学会XX"拆到可单独训练的最小单元。例："学会Python" → 拆为「读代码」「写循环与函数」「调试」「用库解决问题」「组织工程结构」，各自的训练法完全不同。

### 2. 专注 + 限时
单次训练块 25-90 分钟，一个块只练一个子技能。多任务练习是进步杀手。

### 3. 即时反馈回路（最关键）
每个子技能必须预先绑定反馈来源，按优先级：
1. **可验证产出**：代码跑通/测试通过/作品发布
2. **量化指标**：正确率、速度、错误类型统计
3. **专家/同伴评审**：社区点评、导师批改
4. **自我对照**：与范例逐项对比（下策，但好过没有）

无反馈来源的子技能，先解决反馈问题再开始练。

### 4. 走出舒适区 + 重新进入学习区
- 难度标尺：失败率 15-20% 的任务进步最快（太容易→无增长，太难→崩溃放弃）。
- 卡壳超过预设阈值（如 30 分钟无进展）→ 不是硬扛，而是：退半步降低难度 / 补前置概念 / 换材料。
- 定期"刻意不练习"：睡眠和间隔本身就是巩固环节。

## 心理表征（Mental Representations）

刻意练习的本质是**构建高质量心理表征**——专家脑中那套"看到局面就知道走向"的模式。
- 训练法：大量接触优质案例并预测结果 → 对比真实结果 → 分析偏差（棋手打谱、医生看片都是这个结构）。
- 学习新领域时问：这个领域的专家"看一眼就知道"什么？如何让我尽早开始练这种"看一眼"？

## 设计难度序列的方法

1. 找到该领域公认的入门作品/经典习题集/最小项目。
2. 按依赖关系排成阶梯，每级跨一步。
3. 每级定义"过关标准"（不是"看完了"，而是"能独立做出XX"）。
4. 预设每级的卡壳信号与降级路径。

## 在学习方案中的落点

- 每周计划中区分「输入时段」（学概念）与「训练时段」（练子技能），比例约 3:7。
- 每次训练时段必须写明：练哪个子技能、用什么材料、反馈从哪来、过关标准是什么。
