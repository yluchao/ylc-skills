# 整体性学习（认知层）

源自 Scott Young《如何高效学习》（Learn More, Study Less）。用于高效获取和内化知识，替代机械记忆。

## 整体性学习顺序

```
获取 → 理解 → 拓展 → 纠错 → 应用 → 测试(贯穿全程)
```

1. **获取**：压缩信息，抓住要点。手段：快速阅读、指读法、积极阅读（读前提问，读后总结）。
2. **理解**：明白字面意思。卡在术语上就查，不硬读。
3. **拓展**（核心）：将新知识接入已有知识网络。三种方向：
   - **纵向拓展**：与同领域其他概念比较（深度）
   - **横向拓展**：与其他领域类比（"这个像什么？"）
   - **纵向深挖**：追溯来源——谁提出的、解决什么问题（历史）
4. **纠错**：删掉错误联系。手段：做题、与现实对照、找人辩论。
5. **应用**：找用到它的场景。知识用了才长在身上。
6. **测试**：每步自问——我听过吗？懂字面吗？能类比吗？哪里可能错？哪里能用？

## 五种信息类型与对应学法

| 类型 | 例子 | 学法 |
|---|---|---|
| 随机信息 | 术语表、参数 | 联想法、挂钩法、压缩笔记 |
| 观点信息 | 各家理论流派 | 快速扫读 + 比较立场 |
| 过程信息 | 编程、操作技能 | 内在化（想象操作过程）+ 反复实操 |
| 具体信息 | 案例、实验 | 感官体验、画图 |
| 抽象信息 | 数学、原理 | 移动法（搬到具体例子）、比喻 |

诊断新领域由哪类信息构成，为每类信息分配对应学法。

## 核心技术

- **比喻法**：为每个地基概念强制找一个生活比喻（"梯度下降像蒙眼下山，每步踩最低处"）。比喻不完美没关系，找比喻的过程本身就在建立联系。
- **内在化**：把概念转成脑内动态画面 + 体感。
- **图表法**：概念图画成流程图/关系图，一张图胜过十页笔记。
- **费曼技巧**（纠错与理解的最强检验）：
  1. 把概念写在本子顶部
  2. 假装教一个完全不懂的人（或真的教）
  3. 卡壳/只能说行话的地方 = 理解漏洞
  4. 回到材料补漏洞，再简化比喻，直到顺畅
- **压缩笔记**：把整门课压成一页" cheat sheet "，压缩过程即高强度的拓展练习。

## 学习弱点诊断

| 症状 | 弱点环节 | 处方 |
|---|---|---|
| 读得慢、抓不住重点 | 获取 | 快速阅读训练、预习提问 |
| 每个词都懂连起来不懂 | 理解 | 退回前置概念、查术语 |
| 单点会、串不起来 | 拓展 | 画概念图、强制比喻 |
| 自以为会、一做就错 | 纠错 | 费曼技巧 + 做题对照 |
| 考试会、实际不会用 | 应用 | 找真实项目/场景 |

用户汇报"学不进/学不会"时，先按此表诊断环节，再开处方，不要笼统建议"多复习"。

## 能量管理

- 学习是冲刺-休息循环，不是马拉松。计划必须包含休息与睡眠。
- 高能量时段安排拓展/训练（难的事），低能量时段安排获取（相对容易的事）。
- 每周留一天不学新内容，只做复盘与纠错。
